# Wolf GPS V17

إصدار V17 من مشروع Wolf GPS على iOS (Rootless).

## الجديد

- توحيد شاشة التفعيل ومنع طلب الكود مرتين.
- الربط مع `https://key.p3nd.fun/activation/api`.
- رسالة نجاح واضحة بعد قبول الكود مع زر **دخول**.
- مزامنة جلسة Keychain مع حالة الترخيص المستخدمة في اللوحة.
- إصلاح حذف المفضلة نهائيًا وعدم عودتها.
- إصلاح مسارات GPX المنفصلة ومنع القفز إلى البداية.
- إصلاح ظهور اقتراحات البحث فوق عناصر Bottom Sheet.
- واجهة Glass/Blur، وضع فاتح وداكن، وعربية/إنجليزية.
