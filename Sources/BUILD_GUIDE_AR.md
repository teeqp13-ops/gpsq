# دليل بناء ملفات .deb باستخدام بيئة Theos و Makefile

تُعد بيئة **Theos** هي الإطار البرمجي الأكثر شيوعاً لبناء وتجميع أدوات نظام iOS (Tweaks). تعتمد هذه العملية بشكل أساسي على ملف **Makefile** الذي يدير عملية التجميع (Compilation) والربط (Linking) لإنتاج حزمة تثبيت نهائية بصيغة **.deb**.

---

### أولاً: المتطلبات الأساسية للبيئة
قبل البدء في عملية البناء، يجب التأكد من توفر الأدوات التالية على جهاز الكمبيوتر الخاص بك (يفضل نظام macOS أو Linux/WSL):

1.  **Theos**: إطار العمل الرئيسي الذي يحتوي على المكتبات والأدوات اللازمة.
2.  **iOS SDK**: ملفات النظام الخاصة بشركة Apple التي تسمح للأداة بالتفاعل مع واجهات برمجة التطبيقات (APIs).
3.  **Clang/LLVM**: المترجم البرمجي الذي يحول الأكواد إلى لغة الآلة.
4.  **dpkg**: الأداة المسؤولة عن ضغط الملفات وتوليد حزمة `.deb`.

---

### ثانياً: شرح مكونات ملف Makefile
يعمل ملف **Makefile** كخريطة طريق للمترجم البرمجي، حيث يحدد له الأهداف والمكتبات المطلوبة. إليك جدول يوضح أهم المتغيرات المستخدمة في المشروع الذي قمنا ببنائه:

| المتغير | الوصف | مثال |
| :--- | :--- | :--- |
| **TARGET** | يحدد نوع الجهاز المستهدف وإصدار النظام الأدنى. | `iphone:clang:latest:14.0` |
| **ARCHS** | يحدد المعماريات المدعومة (مثل arm64 للأجهزة الحديثة). | `arm64 arm64e` |
| **TWEAK_NAME** | الاسم التعريفي للأداة داخل النظام. | `WolfGPS` |
| **FILES** | قائمة بجميع ملفات المصدر (.mm أو .x) التي يجب تجميعها. | `Source/WFGPSPanel.mm ...` |
| **FRAMEWORKS** | المكتبات الرسمية التي تعتمد عليها الأداة. | `UIKit MapKit CoreLocation` |
| **CFLAGS** | خيارات المترجم الإضافية (مثل تفعيل ARC). | `-fobjc-arc` |

---

### ثالثاً: خطوات عملية البناء (The Build Process)

لتحويل الكود المصدري الذي استلمته في ملف `WolfGPS_Pro_Ultra_Final_Linked.zip` إلى ملف جاهز للتثبيت، اتبع الخطوات التالية بدقة عبر واجهة السطر البرمجي (Terminal):

#### 1. الانتقال إلى مجلد المشروع
يجب أن تكون داخل المجلد الرئيسي الذي يحتوي على ملف `Makefile`.
```bash
cd /path/to/WolfGPS_Final
```

#### 2. تنظيف عمليات البناء السابقة (اختياري)
لضمان بناء نظيف وخالٍ من بقايا ملفات قديمة، استخدم الأمر التالي:
```bash
make clean
```

#### 3. بدء عملية التجميع وتوليد الحزمة
هذا هو الأمر الرئيسي الذي يقوم بقراءة ملف `Makefile` وتجميع الأكواد ثم ضغطها في ملف `.deb`.
```bash
make package
```
*   **ملاحظة**: إذا كنت ترغب في ضغط الملف بأعلى درجة توافق، استخدم `make package FINALPACKAGE=1`.

#### 4. العثور على الملف النهائي
بعد اكتمال العملية بنجاح، سيقوم نظام Theos بإنشاء مجلد جديد باسم `packages`. ستجد بداخله ملف التثبيت النهائي، ويكون اسمه عادةً بالتنسيق التالي:
`com.wolfox.wolfgps_1.0.0_iphoneos-arm.deb`

---

### رابعاً: شرح ملف Control (المعلومات الوصفية)
بجانب ملف `Makefile` يوجد ملف يسمى **control**، وهو ضروري جداً لتعريف الحزمة لمتجر السيديا (Cydia) أو Zebra. يحتوي على:
*   **Package**: المعرف الفريد (مثلاً `com.wolfox.wolfgps`).
*   **Name**: الاسم الذي سيظهر للمستخدم.
*   **Version**: رقم الإصدار.
*   **Architecture**: المعمارية (عادة `iphoneos-arm`).
*   **Description**: وصف موجز لوظيفة الأداة.

---

### خامساً: نصائح هامة لتجنب الأخطاء
1.  **مسارات الـ SDK**: تأكد من أن مسار الـ SDK داخل مجلد Theos صحيح (عادة في `$THEOS/sdks/`).
2.  **الأذونات**: إذا واجهت خطأ "Permission Denied"، قد تحتاج لاستخدام `sudo` أو تصحيح ملكية مجلد Theos.
3.  **الاعتمادات (Dependencies)**: إذا كانت الأداة تعتمد على أدوات أخرى، يجب ذكرها في ملف الـ `control` تحت حقل `Depends`.
